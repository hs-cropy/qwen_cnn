# Cropy 기능 선택 LLM 학습 보고서

농가가 말로 묻는 질문을 앱이 실행할 기능 하나로 바꾸는 **Qwen3.5-2B 미세조정 모델**의 데이터셋 구성, 학습 단계별 성과, 채택 모델과 배포 형태별 성능을 정리한 보고서입니다.

## 👉 [보고서 바로 열기](https://hs-cropy.github.io/qwen_cnn/)

## 요약

| 항목 | 값 |
|---|---|
| 기본 모델 | `Qwen/Qwen3.5-2B` (LoRA r16, 새 토큰 10개 학습 후 병합) |
| 출력 형식 | `<hs_번호>(인자=정수)<hs_end>` 한 줄, 기능 9개 |
| 데이터 | v2c 6,222행 (학습 5,062 / 검증 1,160, 검증은 사람 검수) |
| 채택 모델 | 세 번 학습한 모델의 가중치 평균 (`soup_v2_v2b_v2c`) |
| 정확도 (검증 1,160건) | 형식 100% · 기능 98.4% · 인자까지 **97.0%** |
| 보드 int8 (RKLLM W8A8, 2.74GB) | 인자까지 98.0% (같은 300건에서 원본 98.3%) |
| 웹 4비트 (ONNX q4f16, 1.34GB) | 인자까지 97.3% (같은 300건에서 원본 98.3%) |
